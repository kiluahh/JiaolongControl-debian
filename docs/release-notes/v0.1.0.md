# v0.1.0 — 首个 Debian / Linux 版

把 Windows 上的 JiaoLongControl 搬到 Linux：一个和原版一样的面板，管性能模式、风扇、键盘背光、
触摸板、温度功耗曲线和屏幕 OSD。硬件访问用 `acpi_call` 读写 EC，不需要内核模块补丁。

## 安装

```bash
sudo apt install ./jiaolongcontrol_0.1.0_amd64.deb
```

装完**注销并重新登录一次**（`jlc` 组生效），然后在应用菜单里打开「蛟龙控制中心 / JiaoLong Control」。

- 适用系统：Debian 13（trixie）amd64，X11 / Wayland 桌面均可（OSD 走 XWayland）
- 开发机：MECHREVO 蛟龙 16 Pro（X6DR55xx-B2，Ryzen 9 8940HX + RTX 5060 Laptop），各项均为实机验证
- 同代 Uniwill / Tongfang 模具（EC 接口 `INOU0000`）理论可用，其它机型不保证

依赖：`acpi-call-dkms`、`nodejs` 会随包自动安装；`ryzen_smu` 是可选模块，
只有「Ryzen SMU」页（CPU 功耗 / 超频）需要，需自行编译。

## 功能

- **仪表盘**：CPU 频率 / 温度 / 占用、GPU 占用 / 温度 / 显存、风扇转速、实时曲线、内存与系统信息
- **性能模式**：高性能 / 平衡 / 静音，与机身指示灯、风扇同步
- **风扇**：实时转速；自动 / 全速两档（本机 EC 只支持这两个，见下）
- **键盘**：背光档位 0–4、单色 RGB、呼吸灯
- **触摸板**：一键开关
- **CPU**：TDP、EDC、温度墙、Curve Optimizer（全核 / 分核）、整包功耗（RAPL 实测）
- **GPU**：核心 / 显存最低频率锁定
- **屏幕 OSD**：性能模式、风扇、键盘背光、触摸板变化时，从屏幕角落滑入提示，可调位置、动画、停留时长、透明度、缩放
- **开机自动应用**：勾选后每次开机自动套用性能模式、CPU 参数与键盘背光
- **托盘常驻**：关窗口不退出

## 已知限制（如实说明，不提供假开关）

- **没有风扇曲线 / 手动转速**：本机 EC 不接受按转速或占空比写入，多路写入实测转速不变，只有「全速」位有效
- **没有 GPU 曲线超频**：Linux 无 NVAPI VF 曲线接口
- **没有 Caps/Num Lock 模拟切换**：不做 uinput 虚拟键盘注入，面板改为提示按物理键
- 音量不显示 OSD：GNOME 已有原生音量提示
- Logo 灯、逐键 RGB：本机无对应寄存器 / 设备
