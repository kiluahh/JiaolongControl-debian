# v0.1.1 — 新应用图标

只改了外观，功能与 v0.1.0 一致。

- 应用图标换成新的几何标记（透明背景，紫色 `#8b5cf6`）：
  窗口左上角、托盘、应用菜单 / 程序坞、桌面快捷方式全部同步更新
- 换图标后不再需要原来那张插画，安装包体积也小了约 1 MB

## 安装

```bash
sudo apt install ./jiaolongcontrol_0.1.1_amd64.deb
```

已装过旧版的直接覆盖升级即可；升级后**重启一次面板**（关掉窗口再从菜单打开）就能看到新图标。
`jlc-daemon` 会自动重启，不用重新登录。
